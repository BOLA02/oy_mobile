# OyaEat brand assets

All cut from the supplied logo (white background removed, edges kept smooth).

| File | Use |
|---|---|
| `logo_full.png` | Whole logo (icon + wordmark + tagline). Login screen. |
| `logo_mark.png` | Icon only. Splash animation. |
| `logo_wordmark.png` | "OyaEat" lettering. Splash animation. |
| `logo_tagline.png` | "Great Food. Delivered." Splash animation. |
| `icon.png` | Launcher icon for iOS and older Android (white, no transparency). |
| `icon_bg.png` / `icon_fg.png` | Android adaptive icon layers. The foreground is kept small so circle, squircle and square masks never clip it. |
| `splash_blank.png` | Empty image so Android 12's native splash stays plain white. |

The logo is drawn for **light backgrounds** (dark green + orange). Do not place it on dark or
coloured surfaces. A higher-resolution original (or SVG) would make it sharper on large screens.
Brand colours: green `#066432`, orange `#FC6504`.
